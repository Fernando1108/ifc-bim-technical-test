# IFC BIM Technical Test

Aplicación web local para cargar, procesar, visualizar y analizar modelos IFC.

## Estado del proyecto

Fase 0: inicialización del repositorio y definición de la arquitectura.

## Estructura inicial

- `frontend/`: aplicación web y visor IFC.
- `backend/`: API, autenticación, procesamiento IFC y persistencia.
- `docs/`: documentación técnica y diagramas.
- `storage/`: almacenamiento local de archivos IFC durante la ejecución.

## Restricciones principales

- Ejecución completamente local.
- Dependencias gratuitas y open source.
- Sin servicios externos ni plataformas comerciales.
- Secretos gestionados mediante variables de entorno.
